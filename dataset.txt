# Dataset Information

## Dataset

**Smithsonian Butterflies Subset**

Hugging Face Dataset ID:

`huggan/smithsonian_butterflies_subset`

Source:

https://huggingface.co/datasets/huggan/smithsonian_butterflies_subset

## Description

This project uses a subset of the Smithsonian Butterflies dataset for training an image diffusion model.

The dataset contains butterfly images that are used to teach the model the visual characteristics of butterflies, such as their shapes, colors, wing patterns, and textures.

The model does not memorize a specific butterfly. Instead, it learns the overall visual distribution of the training images and uses this knowledge to generate new butterfly images from random noise.

## Dataset Size

- 1,000 butterfly images
- One `train` split
- Images have varying original resolutions

## Preprocessing

The images are preprocessed before being given to the diffusion model:

1. Convert images to RGB
2. Resize images to `64 × 64` pixels
3. Convert images to PyTorch tensors
4. Normalize pixel values to the range `[-1, 1]`

## Use in This Project

The dataset is used to train an **unconditional diffusion model** using:

- PyTorch
- Hugging Face Diffusers
- `UNet2DModel`
- `DDPMScheduler`

During training, noise is progressively added to the butterfly images. The U-Net learns to predict the noise added to an image at different timesteps.

After training, the model starts with random Gaussian noise and progressively removes the noise to generate a new butterfly image.

## Future Extension

This project is intended to be extended from unconditional diffusion to **conditional diffusion**.

The planned extension will allow the model to generate butterflies based on a simple condition such as color, for example:

`Blue → Generated blue butterfly`

No natural-language processing is required for this conditioning approach.
